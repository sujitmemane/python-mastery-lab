# How To Use This Course

For every topic:

1. Open `lesson.py` and read only one idea at a time.
2. Predict output before running the example.
3. Trace each value and explain what changed.
4. Open `practice.py` and implement every TODO yourself.
5. Run your code and keep the mistakes; debugging is part of the lesson.
6. If stuck, read only Hint 1, then try again. Continue one hint at a time.
7. Read `solution.py` only after a genuine attempt.
8. Run `python3 -m unittest discover -s tests` when tests exist.
9. Update `PROGRESS.md`, including confidence and revision needs.

Run a file with `python3 path/to/file.py`. Create a virtual environment only when a future lesson explicitly needs a package; the core course uses Python's standard library.

## Mentor Commands

In chat, use `start`, `next`, `explain`, `why`, `hint`, `solution`, `test me`, `harder`, `review`, or `debug`. The response should stay focused on the current lesson and reveal no more than requested.
