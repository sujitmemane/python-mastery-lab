# 04 - Data Structures

This section covers Python's built-in data structures and how to use them well:

- lists, tuples, sets, and dictionaries
- create, read, update, and delete operations
- indexing, slicing, traversal, and mutation
- copying, references, aliasing, and immutability
- comprehensions and nested data

This is not an algorithms or competitive-programming section. The goal is to understand Python's data structures and choose the right one for your code.
