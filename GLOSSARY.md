# Python Glossary

- **Assignment:** Binding a name to an object with `=`.
- **Boolean:** A `True` or `False` value used for logical decisions.
- **Dynamic typing:** Names do not have fixed declared types; objects have types at runtime.
- **Immutable:** An object that cannot be changed after creation, such as `str` or `int`.
- **Mutable:** An object that can change in place, such as `list` or `dict`.
- **Reference:** A relationship between a name and the object it currently identifies.
- **Iterable:** An object that can provide its items one at a time.
- **Iterator:** An object that implements the iterator protocol and remembers its position.
- **Generator:** A lazy iterator commonly created with `yield`.
- **Function:** A named, reusable block of behavior.
- **Scope:** The region where a name can be looked up.
- **Exception:** An event representing an error or unusual control-flow condition.
- **Decorator:** A callable that wraps another callable to extend its behavior.
- **Closure:** A function retaining access to values from its enclosing scope.
- **Descriptor:** An object controlling attribute access through methods such as `__get__`.
- **Coroutine:** An async computation that can pause at `await`.
- **Hashable:** An object with a stable hash value that can be used as a dictionary key.
- **Metaclass:** The class of a class; commonly `type`.
