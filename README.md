# Python Mastery

An implementation-first Python course: understand a small idea, trace it, write code, debug it, and prove that you can use it.

## Start Here

1. Read [HOW_TO_USE.md](HOW_TO_USE.md).
2. Open [01 - Variables](01-basics/01-variables/lesson.py).
3. Predict the output before running it.
4. Complete that topic's `practice.py` without opening `solution.py`.
5. Use one hint at a time, then compare your work with the solution.
6. Update [PROGRESS.md](PROGRESS.md).

## Rules

- This repository teaches Python itself, using only the standard library in lessons.
- Practice files contain prompts and TODOs, never copied solutions.
- A topic is complete after implementation, debugging, and review.
