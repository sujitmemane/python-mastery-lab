# Python Mastery Roadmap

Work from left to right. Each row is a section; its lessons should be split into one concept at a time.

| Section | Topics | Prerequisites | Practice |
| --- | --- | --- | --- |
| 01 Fundamentals | variables, types, conversion, operators, input/output | none | exercises |
| 02 Control Flow | conditions, `for`, `range`, `while`, loop controls, nesting | fundamentals | debugging drills |
| 03 Strings | indexing, slicing, methods, formatting, immutability | fundamentals | text analyzer |
| 04 Collections | lists, tuples, sets, dictionaries, comprehensions | control flow | collection problems |
| 05 Functions | parameters, return, scope, `*args`, `**kwargs` | fundamentals | reusable utilities |
| 06 Pythonic Python | readability, EAFP, duck typing, `enumerate`, `zip` | functions, collections | refactoring practice |
| 07 Errors and Exceptions | built-in errors, `try`, `raise`, custom exceptions | control flow | broken-code lab |
| 08 File Handling | paths, text, modes, `with` | exceptions | notes and log tools |
| 09 Modules and Packages | imports, `__main__`, packages, relative imports | functions | multi-module project |
| 10 Environments | `venv`, `pip`, requirements, isolation | modules | repeatable setup |
| 11 OOP | classes, objects, methods, `self`, inheritance, composition | functions | domain models |
| 12 Advanced OOP | properties, ABCs, protocols, dunder methods | OOP | custom collection |
| 13 Built-in Structures | references, copying, hashing, mutability | collections | aliasing lab |
| 14 `collections` | `Counter`, `defaultdict`, `deque`, named tuples | collections | frequency and queue tools |
| 15 Iterators and Generators | protocols, `iter`, `next`, `yield`, laziness | functions | custom iterator library |
| 16 Decorators and Closures | nested functions, closures, `nonlocal`, decorators | functions | logging and timing decorators |
| 17 Context Managers | `with`, `__enter__`, `__exit__` | OOP, exceptions | resource manager |
| 18 Type Hints | built-in types, unions, callable, generics | functions | typed utilities |
| 19 Dataclasses and Enums | `@dataclass`, frozen values, `Enum`, `auto` | OOP | model redesign |
| 20 Regular Expressions | matching, groups, substitution, lookarounds | strings | text extraction |
| 21 Datetime | dates, times, deltas, formatting, time zones | types | schedule utility |
| 22 Pathlib, OS, Sys | filesystem scripts, environment, arguments | files | file organizer |
| 23 JSON and CSV | loading, dumping, readers, writers | collections, files | data-backed CLI |
| 24 Functional Python | `lambda`, `map`, `filter`, `reduce`, `partial` | functions | readability comparisons |
| 25 Testing | `assert`, unittest, pytest concepts, fixtures, mocks | functions | tested projects |
| 26 Logging and Debugging | tracebacks, breakpoints, `pdb`, loggers | exceptions | debugging lab |
| 27 Concurrency | threads, locks, processes, queues, models | functions | concurrent processor |
| 28 Asyncio | coroutines, event loop, tasks, `gather` | functions | async task runner |
| 29 Performance | complexity, `timeit`, profiling, memory | collections, functions | measure before optimize |
| 30 Python Internals | object model, references, GC, CPython details | advanced OOP | memory experiments |
| 31 Advanced Language Features | descriptors, `__slots__`, metaclasses | internals, OOP | carefully scoped experiments |
| 32 Packaging | `pyproject.toml`, metadata, local installs | modules | Python package |
| 33 Pythonic Design | APIs, small functions, composition, quality | all previous | design review |
| 34 DSA with Python | stacks, queues, trees, graphs, search, sorting | collections, functions | algorithm drills |
| 35 Final Projects | CLI, file engine, package, concurrent and async tools | roadmap complete | portfolio projects |

Difficulty rises from Level 1 (syntax) to Level 6 (advanced). Do not skip practice to reach advanced topics faster.
