# 02 - Control Flow

Control flow lets a program choose actions and repeat actions. Complete these concepts in order.

## Lesson Plan

| Order | Concept | Difficulty | Practice goal |
| --- | --- | --- | --- |
| 1 | `if` statements | Level 1 | Make a decision from a condition |
| 2 | `elif` and `else` | Level 1 | Handle multiple outcomes |
| 3 | `for` loops | Level 2 | Process each item in a sequence |
| 4 | `range()` | Level 2 | Repeat over a number sequence |
| 5 | `while` loops | Level 2 | Repeat while a condition is true |
| 6 | `break`, `continue`, and `pass` | Level 3 | Control loop behavior |
| 7 | Nested loops | Level 4 | Work with repeated groups |

## Workflow

For every lesson, use this order:

1. Read and run `lesson.py`.
2. Predict the output before running it.
3. Solve `practice.py` without copying the solution.
4. Open `hints.md` only when stuck.
5. Compare with `solution.py` after trying.

Start with [01 - if statements](01-if/lesson.py).
